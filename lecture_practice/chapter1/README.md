# 1장 실습: 공간 데이터를 처음 열어 보기

이번 실습의 목적은 분석 실력이 아니라 **환경이 제대로 준비됐는지 확인하는 것**이다. 코드 한 개를 돌려 내 컴퓨터에서 공간 데이터가 열리는지 보고, AI 에이전트와 처음 대화해 본다.

## 시작 전에

`lecture_practice/README.md`의 1-5단계를 마쳤어야 한다. 아직이면 거기부터 한다. 터미널 앞에 `(.venv)`가 붙어 있는지 확인한다.

## 1. 코드 돌리기

```
python lecture_practice/chapter1/code/1-1-geoai-tools-preview.py
```

전 세계 국가 경계 데이터를 인터넷에서 받아 와 대륙별로 세어 보는 코드다. 처음 실행하면 데이터를 받느라 몇 초 걸린다.

## 2. 결과 맞춰 보기

아래 값이 나오면 정상이다. 이 값은 macOS(Python 3.14)와 Windows(Python 3.12)에서 각각 돌려 **완전히 같게** 나온 값이다.

```
전체 국가 수: 177
좌표계(CRS): EPSG:4326
아시아 국가 수: 47
데이터 형태: (177, 169)
```

숫자가 다르게 나오면 데이터를 받아 온 시점의 판본이 달라졌을 수 있다. 실행 화면 전체를 복사해 수업 게시판에 올린다. 혼자 판단하지 말고 그대로 옮기면 된다.

### 왜 이 숫자들이 중요한가

- **177**: 국가 수가 195개가 아니다. 이 데이터가 어떤 기준으로 "국가"를 세는지에 따라 답이 달라진다. 데이터를 쓸 때 **누가 어떤 기준으로 만들었는지**를 먼저 봐야 하는 이유다.
- **EPSG:4326**: 위도·경도로 위치를 적는 좌표계다. 지구를 평면으로 펴지 않은 상태라 **거리와 면적을 재면 틀린다.** 2장에서 본격적으로 다룬다.
- **(177, 169)**: 177개 행(국가), 169개 열(속성). 공간 데이터는 지도 모양만 있는 게 아니라 인구·대륙 같은 속성 표가 함께 붙어 있다.

## 3. 경고 메시지를 그냥 넘기지 않기

실행하면 중간에 이런 경고가 뜬다.

```
UserWarning: Geometry is in a geographic CRS. Results from 'area' are likely
incorrect. Use 'GeoSeries.to_crs()' to re-project geometries to a projected CRS
before this operation.
```

오류가 아니라 경고라서 코드는 끝까지 돌지만, **결과 숫자는 믿을 수 없다는 뜻**이다. 코드는 위도·경도 상태에서 면적을 계산했고, 그래서 "아시아 면적 상위 5개국"에 카자흐스탄과 몽골이 들어가 있다. 실제 면적 순위와 다르다. 위도가 높을수록 면적이 부풀려지기 때문이다.

이 실습의 진짜 과제가 여기 있다.

## 4. AI 에이전트와 함께 고쳐 보기

에이전트 대화창에 순서대로 물어본다. 답을 받아 적기만 하지 말고, 무슨 말인지 이해될 때까지 되묻는다.

1. **원인 이해**
   ```
   lecture_practice/chapter1/code/1-1-geoai-tools-preview.py 를 돌렸더니
   "Geometry is in a geographic CRS" 경고가 떴어.
   왜 이런 경고가 나는지, 위도 경도로 면적을 재면 뭐가 잘못되는지
   그림 그리듯 쉽게 설명해줘. 코드는 아직 고치지 마.
   ```

2. **계획 세우기**
   ```
   이 경고를 없애고 면적을 제대로 계산하려면 어떤 순서로 고쳐야 해?
   코드 말고 단계만 알려줘.
   ```

3. **직접 고치고 실행**
   에이전트가 제안한 순서대로 코드를 고친 뒤(원본을 지우지 말고 `1-1-my-version.py`처럼 복사해서 고친다) 실행한다.

4. **결과 검증**
   ```
   고친 코드로 다시 계산한 아시아 면적 상위 5개국은 이렇게 나왔어. (결과 붙여넣기)
   원래 결과와 순위가 어떻게 달라졌고, 왜 달라졌는지 설명해줘.
   ```

**확인할 점**: 고친 뒤에도 순위가 그대로라면 좌표계 변환이 실제로 적용되지 않은 것이다. 에이전트에게 "정말 반영됐는지 어떻게 확인하지?"라고 물어본다.

## 5. 스스로 답해 보기

에이전트에게 묻지 말고 먼저 혼자 답해 본다. 막히면 그때 묻는다.

1. 이 데이터에서 "국가"가 177개인 이유를 한 문장으로 설명할 수 있나?
2. 좌표계를 바꾸지 않고 면적을 계산하면 어느 지역이 특히 부풀려지나? 왜 그런가?
3. 내가 사는 지역의 문제를 이런 데이터로 분석한다면, 무엇을 세고 무엇과 비교하겠나?
