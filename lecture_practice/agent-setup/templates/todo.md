# 할 일 (todo.md)

> 큰 요청 하나를 통째로 던지면 에이전트는 일부를 빠뜨린다. 할 일을 쪼개 여기 적고
> 하나씩 시킨다. 끝낸 것은 `[x]`로 바꾼다. 세션을 시작할 때 "todo.md 보고 다음 것 하나만 하자"라고 말한다.

## 하는 중

- [ ] (지금 붙잡고 있는 것 하나만 여기 둔다)

## 할 일

- [ ] (예: 격자별 특성 6개 만들기)
- [ ] (예: 공간 교차검증으로 점수 재기)
- [ ] (예: 상위 20개 격자 지도로 그리기)
- [ ] (예: 결과를 정책 제안 3줄로 정리하기)

## 끝낸 것

- [x] (예: 데이터 준비 코드 4-0 실행, 격자 1,024개 생성 확인)

## 확인이 필요한 것

에이전트 말만 믿고 넘기면 안 되는 것들을 적어 둔다.

- [ ] (예: 숫자가 이상하게 큰 이유 - 단위가 m인지 km인지 확인)
- [ ] (예: 교수님께 질문 - 분석 단위를 격자로 해도 되는지)
