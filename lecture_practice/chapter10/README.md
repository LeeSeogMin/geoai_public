# 10장 실습: 다음 주 민원 예측과 예측구간

이 실습은 `lecture/ch10.md` 6~7절(시공간 예측, 시간 블록 검증, 정규화 conformal 예측구간)을 코드로 확인하는 목적입니다. 결과 로그는 실행하면 `lecture_practice/chapter10/results/`에 저장됩니다.

요구사항

- 루트에 `.venv` 가상환경이 생성되어 있고 활성화되어 있어야 합니다. 아직이면 `lecture_practice/README.md`의 설치 지침을 먼저 따르세요. **신규 의존성은 없습니다.**
- **실습 자료는 `data/` 폴더에 들어 있습니다. 내려받거나 먼저 실행할 코드는 없습니다.**

`data/` 폴더의 자료 (가상 자료)

| 파일 | 내용 |
| --- | --- |
| `complaint_road.parquet` | 격자 256개(16×16)의 도로·활동 밀도 0~1 (열 `cell, road`) |
| `complaint_obs.parquet` | 40주 × 256격자의 주별 민원 건수 10,240행 (열 `t, cell, count`) |

가상 자료를 만든 규칙 (생성 코드는 저장소에 없고 만들어진 파일만 들어 있습니다. 난수 시드 42)

- 민원 ~ 푸아송(기저 1.2 + 4.0 × 도로 + 0.35 × 직전 주 자기 건수 + 0.35 × 직전 주 이웃 평균) × 계절성(진폭 0.25, 26주 주기) × 신고 성향(0.7~1.3, 저장하지 않음)
- 시간 지속성 0.35 + 공간 확산 0.35 = 0.70 < 1이라 건수가 발산하지 않습니다. 공간 확산을 넣어 만들었으므로 공간 시차가 예측에 도움이 되는 것이 정답입니다.

실습 파일

- `lecture_practice/chapter10/code/10-2-civil-complaint-forecast.py` — 다음 주 민원 시공간 예측, 공간 시차 효과 비교, 예측구간과 신뢰등급

실행 방법 (Windows cmd/PowerShell / macOS Linux)

```bash
python lecture_practice/chapter10/code/10-2-civil-complaint-forecast.py
```

예상 결과(검증 포인트)

- 데이터: 격자 `256개` × `40주`(분석 12~39주), 분석 기간 민원 `126,117건`
- 예측: 시간 시차만 R² `0.753`, MAE `6.510` → 공간 시차 추가 R² `0.813`, MAE `5.498`
- 피처 중요도: `self_t 0.589`, `neigh_t 0.364`, 나머지는 모두 0.02 아래
- 예측구간: 90% 구간 포함률 `0.901`, 반폭 중앙값 `8.82`건, 범위 `[5.41, 119.80]`
- 권역 우선순위: 예측 상위 두 권역(0, 1)이 신뢰등급 `낮음`

검증 팁

- 학습·평가는 **시간 블록**으로 나눕니다(앞 70% 주 학습, 뒤 30% 주 평가). 무작위로 나누면 미래 자료로 과거를 맞히게 되어 점수가 실제보다 좋게 나옵니다.
- 자료가 저장소에 고정되어 있으므로 모든 학생이 같은 숫자를 얻습니다(학번 시드를 쓰지 않습니다).
- 예측구간 계산은 평가 구간의 잔차를 σ̂ 적합과 분위 계산에 함께 쓰는 교육용 근사입니다. 포함률이 다소 낙관적일 수 있습니다.
