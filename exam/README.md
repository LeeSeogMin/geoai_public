# 중간고사 작성 방법 안내

이 폴더는 중간고사 문제와 제출 도구가 들어 있는 폴더다. **문제는 [시험지.md](시험지.md)에 있고, 이 파일은 문제를 푸는 순서와 제출 방법만 안내한다.** 시험지를 먼저 읽는다.

## 1. 한눈에 보기

1. 최신 자료를 받는다.
2. 문제 하나씩 원본 코드를 돌려 본다 (`q1.py` ~ `q6.py`).
3. 원본을 복사해 `q1_fixed.py` ~ `q6_fixed.py`로 저장하고, 결함을 고쳐 다시 돌린다.
4. 6문제를 마치면 제출 파일을 만든다 (`submit_exam.py`).
5. 만들어진 `submissions/중간고사_학번.md`의 `>> 답:` 아래에 답을 쓰고, 이 파일 **하나**를 LMS에 올린다.

## 2. 최신 자료 받기

1~7장 실습 환경(저장소 루트의 `.venv`)이 이미 있어야 한다. 새로 설치할 패키지는 없다. 환경이 없으면 `명령어.md`의 "3. 환경설정 바이브 코딩"을 먼저 따른다.

내가 고친 실습 코드를 지키면서 새 자료를 받는 순서는 다음과 같다.

```text
git stash
git pull origin main
git stash pop
```

받은 뒤 저장소 루트에 `exam/` 폴더가 있고 그 안에 `q1.py`가 있는지 확인한다.

## 3. VS Code에서 여는 위치

**저장소 루트(`geoai_public`)를 연다.** `exam/` 폴더만 열면 `.venv`가 한 단계 위에 있어서 아래 명령의 경로가 달라진다.

| 연 위치 | Windows | macOS |
|---|---|---|
| 저장소 루트 (권장) | `.venv\Scripts\python exam\q1.py --id 학번` | `.venv/bin/python exam/q1.py --id 학번` |
| `exam/` 폴더 | `..\.venv\Scripts\python q1.py --id 학번` | `../.venv/bin/python q1.py --id 학번` |

이후 명령은 저장소 루트에서 연 것으로 쓴다. `학번`에는 내 학번을 그대로 쓴다. **모든 문제에서 같은 학번을 쓴다.** 학번이 바뀌면 자료가 바뀌어 수정 전·후 비교가 맞지 않는다.

## 4. 문제 하나를 푸는 순서

문제 1을 예로 든다. 문제 2~6도 파일 이름의 숫자만 바꾸면 같다.

**① 원본을 돌려 본다.** 오류 없이 숫자가 나온다. 이 숫자가 "수정 전" 값이다.

```text
.venv\Scripts\python exam\q1.py --id 학번
```

출력의 맨 아래에 `@@KEY 이름=값` 줄이 있다. 이 줄은 채점에 쓰이므로 지우지 않는다.

**② 복사본을 만든다.** 원본은 고치지 않는다.

| Windows | macOS |
|---|---|
| `copy exam\q1.py exam\q1_fixed.py` | `cp exam/q1.py exam/q1_fixed.py` |

**③ `q1_fixed.py`를 읽고 결함을 찾는다.** 한 곳을 고치고 다시 돌려, 숫자가 어떻게 바뀌는지 본다. 한 번에 여러 곳을 고치면 무엇이 효과였는지 알 수 없다.

```text
.venv\Scripts\python exam\q1_fixed.py --id 학번
```

**④ 시험지가 요구한 `@@KEY` 줄이 모두 출력되는지 확인한다.** 줄 이름은 시험지의 문제마다 "수정본이 출력할 줄"에 적혀 있다. 값은 직접 적지 말고, 계산한 변수를 출력한다.

## 5. 제출 파일 만들기

6문제를 마친 뒤 한 번 실행한다.

```text
.venv\Scripts\python exam\submit_exam.py --id 학번 --name 이름
```

macOS는 `.venv/bin/python exam/submit_exam.py --id 학번 --name 이름`이다.

실행하면 `submissions/중간고사_학번.md`가 생긴다. 이 파일에 이미 들어 있는 것은 다음과 같다.

- 문제마다 수정 전 출력
- 수정 후 출력과 수정한 코드 전문
- 답을 쓸 칸 (`>> 답:`)

**할 일은 `>> 답:` 아래에 답을 쓰는 것뿐이다.**

> **주의**: `submit_exam.py`를 다시 실행하면 파일이 새로 만들어져서 **이미 쓴 답이 지워진다.** 코드를 더 고쳐야 하면 고친 뒤에 다시 실행하고, 답은 그다음에 쓴다. 답을 쓴 뒤에 다시 실행해야 한다면 쓴 답을 다른 곳에 먼저 복사해 둔다.

## 6. 답을 쓰는 방법

- 문제마다 내 학번의 숫자를 넣어서 쓴다. "일반적으로 ~하다"만 쓰면 점수를 받지 못한다.
- 표가 필요한 곳은 마크다운 표로 쓰거나, 수정 후 출력에서 숫자를 옮겨 적는다.
- 결함을 찾지 못했거나 코드가 실행되지 않아도 제출한다. 어디까지 했고 어디서 막혔는지 쓰면 그 부분은 부분 점수를 받는다.

## 7. 올리기 전 점검

- [ ] `submit_exam.py`를 **마지막으로 실행한 뒤에** 답을 썼다
- [ ] 문제 1~6 모두 "수정 후 출력"에 `@@KEY` 줄이 있다
- [ ] 서술 답에 내 수치가 들어 있다
- [ ] 올리는 파일은 `중간고사_학번.md` **하나**다

## 8. 자주 막히는 곳

| 증상 | 원인과 처리 |
|---|---|
| `ModuleNotFoundError: No module named 'common'` | `exam/common.py`가 없거나 파일을 다른 폴더로 옮겼다. `exam/` 안에서 그대로 실행한다 |
| `ModuleNotFoundError` (geopandas, sklearn 등) | `.venv`가 아닌 파이썬으로 실행했다. 명령 맨 앞이 `.venv\Scripts\python`(Windows) 또는 `.venv/bin/python`(macOS)인지 본다 |
| `.venv`를 찾을 수 없다 | 1~7장 환경 설정이 안 되어 있다. `명령어.md`의 환경설정 절차를 따르고 `python lecture_practice/check_env.py`로 확인한다 |
| 제출 파일의 "수정 후 출력"이 비어 있다 | `exam/q?_fixed.py` 파일 이름이 다르다. 이름이 정확히 `q1_fixed.py`인지 본다 |
| 제출 도구가 "@@KEY 줄이 출력되지 않음"이라고 알린다 | 수정 과정에서 `key(...)` 줄을 지웠다. 원본 `q?.py`에서 해당 줄을 다시 가져온다 |
| 한글이 깨져 보인다 | 터미널 인코딩 문제다. 제출 파일은 자동으로 UTF-8로 만들어지므로 파일을 열어 확인한다 |
| 같은 오류로 계속 막힌다 | 오류 메시지 전체와 시도한 것을 정리해 수업 게시판에 올린다. 시험 문제의 정답을 묻는 글은 올리지 않는다 |

## 9. 규칙

- AI(코딩 에이전트 포함)를 써도 된다.
- 제출 파일의 출력은 **내 학번으로 실제로 돌려 나온 값**이어야 한다. 다른 사람의 숫자를 옮기면 채점에서 드러난다.
- 원본 `q1.py` ~ `q6.py`, `common.py`, `submit_exam.py`는 고치지 않는다.
- 기한은 10월 19일(월) 00:00부터 10월 24일(토) 23:59까지이다. 기한 안에 언제 풀어도 된다.
