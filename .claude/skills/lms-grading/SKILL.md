# LMS 과제 채점 — 딥러닝영상데이터분석 (geoai_public)

2026-10-23에 이 강의 1~7강을 같은 기준으로 채점하며 정한 절차다. 수강생 11명, 과제당 만점 2점.
이 강의의 과제 제목은 「N강 과제」(1강·3강~7강은 「N강 과제」, 2강은 「2강 과제 제출」)다.

## 1. 채점 기준

| 상태 | 점수 |
|---|---|
| 미제출 | 0점 |
| 제출했고 첨부파일이 있음(파일이 하나라도 있으면 인정) | 2점 |
| 제출했으나 첨부파일 없이 본문에 링크만 씀 | 0점 |

- 내용 품질은 보지 않는다. 파일이 올라왔는지만 본다.
- 링크 제출은 0점이다. 사용자가 MLOps 강의에서 「같은 기준」으로 확정한 규칙을 그대로 따른다. 이 강의는 실제로 링크만 낸 학생이 없었다.
- 중간고사 과제(만점 25)는 대상이 아니다.

## 2. 사전 확인

- 채점 기준과 저장 여부를 사용자에게 먼저 확인한다. 점수 저장은 학생 성적에 반영된다.
- 한 과제를 저장한 뒤 채점 현황을 확인하고 다음 과제로 넘어간다.

## 3. 브라우저: ego-browser만 사용

- Chrome 확장 도구(`mcp__claude-in-chrome__*`)는 쓰지 않는다.
- 사용 전에 `ego-browser skill`로 사용법을 확인한다.
- 사용자가 LMS에 이미 로그인해 두었다. 로그인 정보를 입력하지 않는다.
- 스크립트는 `.mjs` 파일로 저장해 `ego-browser nodejs < file.mjs`로 실행한다. 프로젝트 폴더에 두지 않는다.

## 4. 절차

1. **강의 진입**: 주소를 직접 열면 메인으로 돌아간다. 아래 순서로 들어간다.
   - `https://lms.hs.ac.kr/lms/myLecture/doListView.dunet?mnid=201008840728` 로 이동
   - 강의 카드 「딥러닝영상데이터분석(Adivision)」 클릭 (`text=딥러닝영상데이터분석`)
   - `a[href="/lms/class/report/prof/doListView.dunet"]`(Assignment Management)을 `evaluate`로 클릭
2. **과제 행 찾기**: 행 텍스트에 「N강 과제」가 들어 있는 행의 「채점하기」(영문 UI에서는 `innerText`에 「채점」이 든 링크)를 클릭한다.
3. **학생 읽기**: 표의 `tr` 중 `1차`가 있는 행에서 학번(9자리)·이름·「Submit / Not submitted」를 읽는다. 11명이 나온다.
4. **첨부 확인**: 제출자 행의 「View」를 눌러 모달을 연다. 모달은 iframe 안에 있어 `page.snapshot()`의 `text "..."` 줄을 파싱한다.
   - 「첨부파일」과 「content」 사이에 `.확장자 NNNByte` 줄이 몇 개인지 센다.
   - 모달 닫기: `loc=href:javascript:fncCloseLayer();`
5. **점수 입력**: 행 이름으로 `input[type=text]`에 `data-sc` 속성을 붙이고 `page.fill()`로 값을 넣는다. 그 뒤 input·change·keyup·blur 이벤트를 발생시킨다. 이벤트가 없으면 저장이 반영되지 않는다.
6. **저장**: 「저장하기」 링크(`href="#"`)를 클릭한다. 「저장완료」 알림창이 뜨므로 `page.acceptDialog()`로 닫는다. 이 알림창이 열린 채로 두면 페이지가 멈춘다.
7. **확인**: 과제 목록에서 해당 과제의 「채점 현황」이 `11/11`로 바뀌었는지 본다.

## 5. 진행 기록 (2026-10-23 완료)

| 과제 | 제출 | 첨부 있음 2점 | 0점 | 채점 현황 |
|---|---|---|---|---|
| 1강 | 9명 | 9명 | 미제출 2명(강수진, 김가영) | 11/11 |
| 2강 | 11명 | 11명 | — | 11/11 |
| 3강 | 11명 | 11명 | — | 11/11 |
| 4강 | 11명 | 11명 | — | 11/11 |
| 5강 | 9명 | 9명 | 미제출 2명(김태휘, 신지원) | 11/11 |
| 6강 | 11명 | 11명 | — | 11/11 |
| 7강 | 11명 | 11명 | — | 11/11 |

- 1강 미제출 학생은 강수진, 김가영이다. 2강은 전원 제출·첨부 있음이다.
- 5강 미제출 학생은 김태휘, 신지원이다.
- 이 강의에서는 저장 후 「저장완료」 알림창을 `acceptDialog()`로 닫은 뒤 목록의 채점 현황이 모두 11/11로 반영되었다.

## 6. 주의

- 「중간고사 과제」(만점 25)는 이 절차에 포함하지 않는다.
- 「SMS발송」「쪽지발송」「제출파일일괄다운로드」 등은 사용자 요청 없이 누르지 않는다.
- 값을 지어내지 않는다. 확인하지 못한 학생의 점수는 입력하지 않고 보고한다.
