# 공간 데이터 과학과 GeoAI: 예측·인과추론 기반 의사결정

---

## 핵심 요약

**수업목표 **

본 강의는 공간 데이터와 AI 기법을 결합해 공공정책 문제를 실무적으로 분석·해석할 수 있는 능력을 기르는 것을 목표로 한다. 학생은 공간자료 전처리, 공간단위 피처 설계, 공간 교차검증, 머신러닝·딥러닝 적용, 그리고 분석 결과를 정책 우선순위와 의사결정 산출물로 제시하는 역량을 갖춘다.

**수업운영방식 **

강의는 이론 강의, 코드 시연, 실습·토론, 미니프로젝트로 구성된다. 매주 개념 강의(약 25~35분)→분석·코드 시연(약 25~35분)→결과 해석 및 토론(약 15~20분) 순으로 진행한다. 실습은 제공 코드 실행과 결과 해석 보고를 원칙으로 하며, 중간고사(8주차)와 기말 프로젝트(15주차 발표)를 평가의 핵심으로 삼는다. 개인정보·윤리·검증 절차를 지속 점검한다.

## 1. 강의 설계

### 1.1 대상과 운영

- 대상: 지리·도시·환경·행정·정책·데이터 분야 학부생
- 권장 배경: Python과 기초 데이터 분석 경험. GIS나 원격탐사 경험은 없어도 된다.
- 수업 기간: 15주
- 수업 구성: 강의, 코드 시연, 공간 데이터 분석, 정책 사례 토론, 미니프로젝트
- 학습 자료: 강의교재, 실행 가능한 실습 코드, 실제 공간 데이터와 공개 정책 자료
- 중간고사: 8주차
- 기말 프로젝트 및 발표: 15주차

### 1.2 설계 원칙

1. GeoAI를 영상 분석에만 한정하지 않고, 행정구역·격자·필지·건물·도로망·생활권을 분석 단위로 삼는 공간단위 모델링까지 다룬다.
2. 기술 장에서도 결과를 정책 단위의 지도, 우선순위표, 시나리오 비교로 연결한다.
3. 분석은 다음 순서로 진행한다.

   `분석 단위 설정 → 자료 결합 → 공간 피처 구성 → 모델링·검증 → 정책 산출물 작성`

4. 예측을 잘하는 것과 정책 효과의 원인을 밝히는 것은 다르다는 점을 반복해서 확인한다.
5. 공간 자기상관, MAUP, 생태학적 오류, 데이터 누수, 편향, 개인정보, 책임성을 기술 성능과 함께 검토한다.
6. 국내 중앙정부와 지방정부의 정책 문제를 중심에 두고, 해외 사례는 방법과 제도 비교가 필요한 경우에만 활용한다.

### 1.3 분석 축

| 분석 축                | 주요 자료·단위                                  | 대표 질문                                          | 관련 장            |
| ---------------------- | ----------------------------------------------- | -------------------------------------------------- | ------------------ |
| 공간단위 기반 GeoAI    | 행정구역, 격자, 필지, 건물, 도로망, 서비스 권역 | 어느 지역이 취약한가? 어디에 자원을 배분할 것인가? | 4장, 7장, 8~13장   |
| 영상·래스터 기반 GeoAI | 위성·항공·드론·SAR·열적외 영상                  | 무엇이 어디에 있는가? 무엇이 변했는가?             | 2장, 3장, 5장, 6장 |

영상 분석은 픽셀 단위 결과에서 끝내지 않는다. 토지피복률, 건물밀도, 침수 건물 수, 보호구역 변화량처럼 정책이 실제로 집행되는 공간단위 지표로 변환한다.

## 2. 강의 개요

### 2.1 교과목명
딥러닝 영상데이터분석(공간 데이터 과학과 GeoAI: 예측·인과추론 기반 의사결정)

### 2.2 강의 목표

이 강의는 공간 데이터를 AI와 결합해 정책 문제를 분석하는 방법을 익히는 것을 목표로 한다. 학생은 GIS와 원격탐사 자료의 구조를 이해하고, 공간단위 머신러닝과 영상 딥러닝을 적용하며, 분석 결과를 정책 우선순위와 효과 평가의 언어로 해석한다.

### 2.3 학습성과

수강 후 학생은 다음을 할 수 있어야 한다.

1. 벡터·래스터·포인트 클라우드 자료와 주요 공간단위를 구분한다.
2. 좌표계, 투영, 공간 조인, 버퍼, 오버레이의 의미를 설명하고 분석에 적용한다.
3. 위성영상과 공간단위 자료를 결합해 정책 분석용 피처를 만든다.
4. 공간 자기상관과 데이터 누수를 진단하고 일반 교차검증의 한계를 설명한다.
5. 머신러닝·딥러닝·세그멘테이션·변화 탐지·파운데이션 모델의 활용 조건을 비교한다.
6. LLM·자율 GIS의 장점과 환각·검증·책임성 문제를 설명한다.
7. 예측, 우선순위화, 인과적 정책평가를 구분한다.
8. 환경·도시·재난안전·복지·보건·지역균형발전 문제에 GeoAI 분석 절차를 설계한다.
9. 분석 결과를 지도와 수치만으로 제시하지 않고, 대상 지역·수혜 집단·불확실성·한계를 포함한 정책 판단으로 보고한다.

### 2.4 핵심 질문

- 공간 정보가 없으면 같은 예측이 왜 정책적으로 달라지는가?
- AI가 공간 문제를 실제로 해결했는지 무엇으로 확인할 것인가?
- 어느 지역이 위험한가와 어느 지역에 개입 효과가 큰가는 어떻게 다른가?
- 좋은 지도와 좋은 정책 근거는 어떤 조건을 갖춰야 하는가?
- 자동화가 행정의 속도를 높일 때 책임은 누가 지는가?

## 5. 평가 방식 권장안

참조 강의계획서의 일반적인 시험·참여 구조를 바탕으로 한 권장안이다. 실제 강좌의 학칙과 담당 교원의 운영 기준에 따라 조정한다.

| 평가 항목     | 비율 | 내용                                                               |
| ------------- | ---: | ------------------------------------------------------------------ |
| 중간고사      |  25% | 1~7장의 개념, 공간 데이터, 모델 검증, 사례 적용                    |
| 기말 프로젝트 |  30% | 국내 정책 문제를 공간단위 자료와 GeoAI로 분석하고 정책 산출물 제출 |
| 기말고사      |  25% | 8~15장의 정책·비즈니스 적용, 인과추론, 책임 있는 GeoAI             |
| 실습·과제     |  15% | 주차별 코드 실행, 결과 해석, 지도·표·짧은 보고서                   |
| 참여·출석     |   5% | 수업 참여, 질문, 짧은 exit ticket, 출석                            |

### 5.1 시험 문항 방향

- 개념 구분: 벡터와 래스터, 예측과 인과, 일반 CV와 공간 CV
- 분석 설계: 분석 단위, 자료 결합, 피처, 검증 방법 선택
- 결과 해석: 성능지표와 정책 의미의 차이, 불확실성, 편향, 적용 한계
- 사례형 서술: 환경·도시·재난·복지·지역정책 중 한 문제에 분석 절차 적용

단순히 모델 이름이나 API 사용법을 외우는 문항은 줄이고, 왜 그 방법을 선택했는지와 결과를 어떻게 책임 있게 해석하는지를 묻는다.

### 5.2 기말 프로젝트

학생은 국내 공공정책 문제 하나를 선택해 다음 산출물을 제출한다.

1. 정책 질문과 분석 대상 공간단위
2. 자료 출처와 결합 방법
3. 공간 피처와 모델 또는 비교 설계
4. 공간 자기상관·누수·편향·불확실성 점검
5. 지도, 표, 우선순위표 또는 시나리오 비교
6. 정책 해석, 적용 범위, 한계, 추가로 필요한 자료

최종 보고서는 “모델 정확도가 높다”에서 멈추지 않고, 누가 어떤 결정을 내릴 때 결과를 어떻게 사용할지까지 설명해야 한다. 인과 식별 근거가 없으면 인과효과라고 부르지 않고 예측·우선순위 결과로 보고한다.

## 6. 수업 운영 방식

### 6.1 기본 수업 흐름

- 0~10분: 지난 시간 복습과 오늘의 정책 질문
- 10~35분: 핵심 개념과 직관적 사례
- 35~60분: 코드·지도·표를 통한 분석 과정 확인
- 60~75분: 결과 해석, 한계 점검, exit ticket

정책 적용 장에서는 강의 시간을 사례 분석과 우선순위표 해석에 더 많이 배정한다. 기술 장에서는 코드 실행보다 분석 단위, 검증 설계, 결과 해석을 중심에 둔다.

### 6.2 공통 분석 체크리스트

- 분석 단위가 정책 집행 단위와 맞는가?
- 좌표계와 공간 해상도가 자료마다 일치하는가?
- 이웃 지역의 유사성과 공간 자기상관을 확인했는가?
- 일반 교차검증이 공간 누수를 만들지 않는가?
- 모델이 틀렸을 때 어느 지역과 집단이 더 큰 피해를 보는가?
- 예측 결과를 인과효과로 과장하고 있지 않은가?
- 개인정보, 낙인효과, 차별적 집행, 이의제기 절차를 고려했는가?
- 최종 산출물이 정책 담당자가 사용할 수 있는 지도·표·시나리오인가?

### 6.3 수업에서 반복할 질문

- 이 분석에서 공간단위는 왜 이 크기여야 하는가?
- 픽셀 단위 결과를 행정구역 단위 정책으로 옮길 때 무엇이 사라지는가?
- 일반 CV에서 좋은 점수가 나와도 실제 다른 지역에서 작동한다고 말할 수 있는가?
- 위험이 높은 곳과 정책 효과가 큰 곳이 다르면 어디에 먼저 개입할 것인가?
- 자동화된 추천을 사람이 거부하거나 수정할 절차가 있는가?

## 7. 권장 참고 자료

강의 자료는 각 장의 본문과 실습 코드에 연결된 검증 자료를 우선 사용한다.

- 프로젝트 목차 및 집필 기준: `contents.md`
- 프로젝트 운영·검증 기준: `CLAUDE.md`
- 학부 강의교재 작성 원칙: `lecture/README.md`
- 장별 강의교재: `lecture/chapter{N}.md`
- 장별 실행 코드와 결과: `lecture_practice/chapter{N}/`
- 정책·방법론 연구자료: `content/research/`
- 공간 데이터·지도·정책 자료: 국가공간정보포털, 공공데이터포털, 통계지리정보서비스(SGIS), 브이월드 및 각 중앙·지방정부의 공식 공개자료

외부 자료의 수치와 제도 설명은 강의 시점의 공식 원문을 다시 확인한다. 특정 모델이나 정책의 최신성은 강의계획서에 고정하지 않고, 해당 주차의 자료와 실습 안내에서 갱신한다.

## 8. 강의의 최종 메시지

GeoAI는 지도를 예쁘게 만드는 기술이 아니다. 공간 데이터를 이용해 정책 문제를 더 잘 보고, 어느 지역에 어떤 지원이 필요한지 비교하며, 정책이 실제로 효과를 냈는지 신중하게 판단하는 도구다. 따라서 좋은 분석은 가장 복잡한 모델을 고르는 데서 시작하지 않는다. 적절한 공간단위와 자료를 정하고, 누수와 편향을 확인하고, 결과의 불확실성과 책임 범위를 밝히는 데서 시작한다.
