# 작업 맥락 (context.md)

> 이 파일은 **내가 지금 무엇을 하고 있는지** 적어 두는 곳이다.
> AI 에이전트는 대화를 새로 시작하면 앞의 대화를 기억하지 못한다. 이 파일을 읽히면
> 매번 처음부터 설명하지 않아도 된다. 세션을 시작할 때 "context.md 읽고 시작해줘"라고 말한다.
> 오래된 내용은 지운다. 길어질수록 쓸모가 떨어진다.

## 지금 하는 것

- 장: (예: 4장 공간단위 머신러닝)
- 목표: (한 문장으로. 예: 격자 단위 침수 취약성을 예측하고 상위 20곳을 뽑는다)
- 마감: (있으면)

## 정한 것

무엇을 왜 그렇게 하기로 했는지 적는다. 나중에 "이거 왜 이렇게 했지?"를 막아 준다.

- (예: 분석 단위는 500m 격자로 한다. 읍면동은 면적 차이가 너무 커서 비교가 어렵다)
- (예: 모델은 랜덤포레스트로 간다. 해석이 중요한 과제라 딥러닝은 쓰지 않는다)

## 쓰는 데이터

- 파일: (예: practice/chapter4/data/grid_features.parquet)
- 만든 코드: (예: 4-0-simdata-prep.py)
- 주의할 점: (예: 좌표계가 EPSG:5179다. 위경도로 바꾸면 면적 계산이 틀어진다)

## 지금 막힌 것

- (예: 공간 교차검증 점수가 일반 교차검증보다 훨씬 낮게 나온다. 정상인지 확인 필요)

## 다음에 할 것

- (예: 상위 20개 격자를 지도에 찍고, 실제 침수 이력과 겹치는지 본다)
