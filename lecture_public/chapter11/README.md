# 11장 실습: 침수위험 우선순위, 예측적 치안의 되먹임 편향, 보험 리스크 등급

이 실습은 `docs/ch11.md`와 `lecture/chapter11.md`의 내용을 코드로 확인하는 목적입니다. 결과 로그는 `practice/chapter11/results/`에 저장되어 있습니다.

요구사항

- 루트에 `.venv` 가상환경이 생성되어 있고 활성화되어 있어야 합니다. 아직이면 `practice/README.md`의 설치 지침을 먼저 따르세요.
- `data/` 폴더의 파일은 저장소에 포함되지 않습니다. **`11-0-simdata-prep.py`를 먼저 실행**해야 나머지가 돌아갑니다.

실습 파일 (실행 순서대로)

- `practice/chapter11/code/11-0-simdata-prep.py` — 격자 지형·강우·범죄·보험 건물 데이터 생성
- `practice/chapter11/code/11-1-flood-risk-priority.py` — 침수위험 공간 예측, 예측구간·신뢰등급·적용가능영역(AoA)
- `practice/chapter11/code/11-2-predictive-policing-bias.py` — 예측적 치안 8라운드 되먹임 시뮬레이션(반면교사)
- `practice/chapter11/code/11-3-insurance-risk-grading.py` — 건물별 홍수 리스크 등급과 보험료 차등(비즈니스), 선택·라벨 왜곡 분리 대조군

실행 방법 (Windows cmd/PowerShell / macOS Linux)

```bash
python practice/chapter11/code/11-0-simdata-prep.py
python practice/chapter11/code/11-1-flood-risk-priority.py
python practice/chapter11/code/11-2-predictive-policing-bias.py
python practice/chapter11/code/11-3-insurance-risk-grading.py
```

예상 결과(검증 포인트)

- 11-1 단위: 격자 `300개`, 행정구역 `6개`. 저지대 평균 침수심 `25.1cm` vs 그 외 `10.3cm`
- 11-1 예측: 비공간 피처 R² `0.781` → 공간 시차 추가 `0.816`(개선 `+0.034`), 랜덤 CV `0.874`(누수 과대추정 `+0.058`)
- 11-1 불확실성: 90% 예측구간 포함률 `0.903`, AoA 밖 격자 `9개`
- 11-1 반전: 예측 침수심 1위인 **행정구역 2의 신뢰등급이 '낮음'**
- 11-2 설계: 격자 `256개`, 8라운드. group A 진짜 범죄율 `8.4` vs group B `8.5`(거의 동일)
- 11-2 8라운드 추이: 기록 기준 R² `0.823 → 0.999` / 순찰-진짜위험 상관 `0.397 → 0.429` / Gini `0.247 → 0.917` / 차별적 영향 `1.370 → 2.001`
- 11-3 단위: 건물 `500채`, 가입률 `55.4%`. 저소득 가입률 `42.3%` vs 고소득 `60.6%`
- 11-3 편향(완전 모델은 교차검증(OOF) 예측, 관측 모델·대조군은 각 표본으로 적합 후 500채 전체 예측): 완전 모델 R² `0.890` vs 관측 모델 `0.669`. 저소득 건물에서는 `0.888` vs `0.588`로 격차가 더 벌어짐. 관측 모델·대조군은 학습 표본을 채점에도 포함하므로 격차는 보수적(과소) 추정
- 11-3 로그 상단의 `관측 모델(가입자 277채, 대상=청구 기록) CV R² 0.520`은 표 11.6의 `0.669`와 **채점 대상이 다른 값**입니다. 앞은 가입자의 청구 기록을, 뒤는 500채의 진짜 침수확률을 맞히는 점수입니다
- 11-3 대조군: 가입 선택만 제거한 무작위 동일크기 표본 R² `0.658`(SD `0.030`, 20회) — 관측 모델과 사실상 같음
- 11-3 불확실성: 정규화 conformal 포함률 `0.906`, 구간폭-예측값 순위상관 `0.236`, 저신뢰 건물 중 최고위험 `43.2%`
- 11-3 역설: 진짜 고위험 건물의 `56.0%`(70/125)가 미가입

검증 팁

- 11-1의 핵심은 우선순위 1위를 맞히는 것이 아니라, **1위인데도 신뢰등급이 낮을 수 있다**는 점입니다. 예측이 높은 것과 그 예측을 믿을 수 있는 것은 다른 이야기입니다.
- 11-2에서 확인할 방향은 네 지표가 **서로 반대로 움직인다**는 것입니다. R²는 오르는데 진짜 위험과의 상관은 오르지 않고, 쏠림과 차별은 커집니다.
- 11-3에서 가장 중요한 줄은 **대조군**입니다. 관측 모델의 성능이 낮다는 사실만으로 "보험 가입 편향 탓"이라고 읽으면 안 됩니다. 가입 선택만 없앤 표본에서도 성능이 거의 같으므로, 선택의 몫은 사실상 0입니다. 편향의 흔적은 평균이 아니라 **저소득 건물에서 유독 더 틀린다**는 쏠림에 있습니다.
- 세 실습 모두 **시뮬레이션**입니다. 11-2는 "관측되지 않는 진짜 범죄율"을, 11-3은 "관측되지 않는 진짜 침수확률"을 심어 두었기에 채점이 가능합니다. 현실에서는 이 채점 자체가 불가능하다는 점이 이 실습들의 요점입니다. 그래서 11-3은 심은 메커니즘마다 그것만 제거한 대조군을 함께 돌립니다.
