# 5장 실습: CNN 위성영상 분류, 기준선 비교, 도입 손익분기

이 실습은 5장의 두 분석을 코드로 확인합니다. 결과 로그는 `practice/chapter5/results/`에 저장되어 있습니다.

요구사항

- 루트에 `.venv` 가상환경이 생성되어 있고 활성화되어 있어야 합니다. 아직이면 `practice/README.md`의 설치 지침을 먼저 따르세요.
- **4장의 실제 Sentinel-2 클립을 그대로 씁니다.** `practice/chapter4/code/4-0-data-download.py`를 먼저 실행해 `practice/chapter4/data/`에 위성영상과 WorldCover 라벨을 만들어 두어야 합니다(위성 파일은 `.gitignore` 대상이라 저장소에 들어 있지 않습니다). 5장에는 별도 `data/` 폴더가 없고, `code/_s2_data.py`가 4장 폴더의 로더를 그대로 불러 씁니다.
- CPU만으로 실행됩니다. GPU가 있으면 자동으로 사용합니다(CUDA → MPS → CPU 폴백).

실습 파일 (실행 순서대로)

| 순서 | 파일 | 역할 | 선행 조건 |
|---|---|---|---|
| 1 | `code/5-1-cnn-sentinel2-classification.py` | 12밴드 패치 분류, Random CV 대 Spatial CV, 모델·밴드 비교, 시드 재현성 점검 | 4장 데이터 |
| 2 | `code/5-2-baseline-vs-cnn.py` | 분석 1 — 분광지수 규칙·로지스틱·랜덤 포레스트 대 CNN을 같은 공간 타일 분할로 비교 | 4장 데이터 |
| 3 | `code/5-3-adoption-cost-breakeven.py` | 분석 2 — 5-2의 실측 성능 격차를 비용으로 환산해 도입 손익분기를 계산 | **5-2 실행 필수** |

예상 결과 (검증 포인트) — 5-1

- 패치 추출: `2,318개` 중 순수 패치만 남겨 4클래스 균형 `724장`(클래스당 `181개`), 초지는 순수 패치 `37개`뿐이라 제외, 공간 타일 `36개`
- 입력 텐서: `(12, 32, 32)` — L2A에는 B10이 빠져 12밴드
- 모델 크기: SimpleCNN `96,804` 파라미터 / MiniResNet `1,231,236` 파라미터
- 검증 비교(Macro-F1): Random 5-Fold `0.966 ± 0.010`, Spatial(타일) `0.966 ± 0.008` — 차이 `−0.000`
- 재현성 점검: 시드 0·1·2에서 과대추정 Macro-F1이 `+0.000 ~ +0.009`로 나옵니다. 차이가 폴드 간 표준편차보다 작다는 뜻이므로 "과대추정이 검출되지 않았다"로 읽고, 어느 쪽이 높은지는 해석하지 않습니다
- 모델 비교(공간 분할): SimpleCNN `0.984`(1.0초), MiniResNet `0.984`(2.3초) — 시간은 CUDA GPU 기준
- 밴드 비교(Macro-F1): RGB 3밴드 `0.973` / RGB+NIR 4밴드 `0.984` / 전체 12밴드 `0.984` — 4밴드에서 천장, 추가 8밴드의 기여 없음
- 클래스별 F1: 산림 `0.987` > 경작지 `0.986` > 수역 `0.980` > 시가지 `0.941`(정밀도 1.000·재현율 0.889, 표본 18개)

예상 결과 (검증 포인트) — 5-2

- 5-1과 **같은 724장**을 씁니다. 패치 수·클래스 구성·타일 수가 5-1 로그와 일치하지 않으면 데이터 구성이 어긋난 것입니다
- 다섯 방법의 Macro-F1 순서: 고정 임계 규칙 `0.514` < 학습된 임계 `0.857` < 랜덤 포레스트 `0.926` < 로지스틱 회귀 `0.934` < CNN `0.967`
- 고정 임계 규칙의 클래스별 F1에서 수역은 `0.983`인데 경작지는 `0.039`여야 합니다. 물의 물리는 임계 없이도 통하지만 NDVI 임계는 이 장면에 맞지 않는다는 뜻입니다
- 같은 지수 3개로 임계만 학습하면 `0.514 → 0.857`로 오릅니다. 이 상승 폭이 이 스크립트의 핵심 결과입니다
- CNN의 이득은 경작지·시가지에 몰려야 합니다(수역·산림은 기준선도 이미 높습니다)
- CNN 시드 3개의 Macro-F1 폭이 `0.004` 수준이고, CNN과 최고 기준선의 격차(`+0.032`)가 그보다 커야 "방향을 말할 수 있다"가 출력됩니다

예상 결과 (검증 포인트) — 5-3

- 패치 1건 손익: 절감 인건비 `1,023원`, 규칙의 추가 오분류비 `1,628원`, CNN의 추가 오분류비 `241원` → 규칙 `−605원`, CNN `+782원`
- 손익분기(연 12회): 사람→규칙 **역전 없음**, 사람→CNN `52.05km²`
- 유료 고해상도 영상: 필요 Δ정확도 `0.065`가 남은 여지 `0.025`보다 커서 전부 "달성 불가"
- 퇴화 검사 세 항목이 모두 "역전 없음"이어야 합니다. 하나라도 손익분기 숫자가 나오면 비용 식의 부호가 틀린 것입니다

검증 팁

- `FileNotFoundError ... chapter4/data/sentinel2_l2a_12band_clip.tif`가 나오면 4장의 데이터 준비를 건너뛴 것입니다.
- `[중단] ch5_perf_handoff.csv가 없다`가 나오면 5-2를 먼저 돌리지 않은 것입니다. 5-3은 성능을 가정으로 채우지 않습니다.
- 학습에는 난수가 들어가고 GPU 연산은 완전히 결정적이지 않으므로 소수점 셋째 자리는 실행마다 흔들립니다. 확인할 것은 방향입니다 — 5-1은 **네 유형 모두 F1 0.95 이상**, **4밴드와 12밴드가 같음**, **Random과 Spatial 차이가 폴드 표준편차보다 작음**. 5-2는 **다섯 방법의 순서**와 **고정 임계 규칙의 경작지 붕괴**. 5-3은 **규칙이 역전 없음, CNN이 이득**이라는 부호.
- 5-3의 비용 파라미터 넷은 `[가정]`입니다. 결론이 그 값에 얼마나 매달려 있는지는 스크립트가 출력하는 민감도 표에서 확인하세요. 오분류 처리비를 1만원으로 낮추면 규칙도 이득으로 돌아섭니다.
- 5-1의 성적이 전반적으로 높은 것은 모델이 뛰어나서가 아니라 **한 유형으로 거의 꽉 찬 순수 패치만 골랐기 때문**입니다. 로그 마지막의 단일 장면 한계 문구를 함께 읽으세요.
