## 예상 결과(검증 포인트)

아래 수치는 상가정보 2026년 6월판, 생활인구 2026-06-12~07-31 기준입니다. **공개 데이터가 갱신되면 숫자가 달라지는 것이 정상입니다.**

- 준비: 강남구 소분류 '카페' `2,123`개, 행정동 `22`개. 생활인구 결합 `99.5%`
- 분석 단위: 카페 `2,113`개(결합분), 자사 `102`개 / 경쟁 `2,011`개 → 자사 점유율 `4.8%`
- 수요: 행정동 `21`개, 낮 활동 인구 합계 `993,215`명. 후보지 250m 격자 `540`개
- 전이율: 중앙값 `4.8%`, 최대 `6.6%` — 흔히 쓰는 30% 상한은 하나도 걸러 내지 못함
- 상한 `6%`에서 처음 구속: 순증 1위가 탈락하고 대안은 `-24.0%`
- 거리~전이율 상관 `-0.333` (자사 매장에서 멀수록 잠식이 준다)
- 민감도: β를 1.5→2.5로 바꾸면 순증이 `721`→`1,478`명으로 두 배가 되지만 **최선 후보의 위치는 이동 0m**
- 퇴화 검사: 총배분 ~ 낮인구 상관 `-0.051`

## 검증 팁

- **가장 중요한 것은 표 14.7입니다.** 순증의 크기는 가정(β, 매력도 A)에 두 배까지 흔들리는데 최선 후보의 위치는 흔들리지 않습니다. 크기는 인용하지 말고 순서만 쓰라는 뜻입니다.
- **자기잠식이 작게 나오는 것은 오류가 아닙니다.** 자사 점유율이 4.8%라 신규 매장이 뺏어오는 손님 대부분이 경쟁 브랜드에서 옵니다. 제약의 구속력은 점유율의 함수입니다.
- **퇴화 검사를 건너뛰지 마세요.** 총배분이 인구와 거의 무상관(-0.051)이라는 사실이 이 모형을 돌릴 값어치를 만듭니다. 상관이 0.9였다면 인구 상위 지역을 고르면 그만이고 흡인 모형은 장식이 됩니다.
- 준비 스크립트는 열 이름을 못 찾으면 **실제 열 목록을 보여 주고 멈춥니다.** 공공 데이터는 갱신하면서 열 이름이 바뀌므로, 조용히 엉뚱한 열을 쓰는 것보다 멈추는 편이 낫습니다.
