# 15장 실습: 지역 실험 설계·시장 단위 합성통제·의사결정 경제학

이 실습은 `docs/ch15.md` 15.7절의 분석을 코드로 확인합니다. 결과 로그는 `practice/chapter15/results/`에 있습니다.

**이 장의 데이터는 합성입니다.** 이유가 둘입니다. 첫째, 이 장의 질문은 "출점 효과가 얼마인가"가 아니라 "어떤 설계와 어떤 추정량이 참값에 닿는가"이므로 참 효과를 알아야 채점할 수 있습니다. 둘째, 국내 기업의 시장 단위 무작위 실험 공개 사례와 국내 상권 자기잠식 학술 실증을 찾지 못해 실데이터로도 판정 기준이 없습니다(리서치 기록: `content/research/ch15-business-causal-inference.md`).

## 요구사항

- 루트에 `.venv` 가상환경이 준비되어 있어야 합니다. 아직이면 `practice/README.md`의 설치 지침을 먼저 따르세요.
- 신규 의존성은 없습니다. numpy, pandas, scipy, matplotlib, pyarrow만 씁니다.
- 원자료 다운로드가 필요하지 않습니다. `15-0`이 데이터를 만듭니다.

## 실습 파일 (실행 순서대로)

- `code/15-0-simdata-prep.py` — 시장 40개(4×10 격자) × 104주 로그 매출 패널 생성. 처치·파급은 얹지 않은 기저 세계
- `code/15-1-geo-experiment-power.py` — 지역 실험 설계 다섯을 1,000회 배정 반복으로 평가(편향·표준오차·검정력·MDE)
- `code/15-2-market-synthetic-control.py` — 시장 단위 합성통제로 출점 효과 추정. 추정 계단 다섯 + placebo 순열추론
- `code/15-3-decision-economics.py` — 임계비·순현재가치·용량 제약. 15-2의 추정 결과를 입력으로 받습니다

## 실행 방법

```bash
.venv\Scripts\python.exe practice\chapter15\code\15-0-simdata-prep.py
.venv\Scripts\python.exe practice\chapter15\code\15-1-geo-experiment-power.py
.venv\Scripts\python.exe practice\chapter15\code\15-2-market-synthetic-control.py
.venv\Scripts\python.exe practice\chapter15\code\15-3-decision-economics.py
```

하네스로 한꺼번에 실행하고 증거를 남기려면:

```bash
.venv\Scripts\python.exe scripts\run_and_capture.py 15
```

전체 실행 시간은 약 10초입니다(1,000회 배정 반복 포함). `15-3`은 `results/15-2-estimate.json`을 읽으므로 `15-2`를 먼저 실행해야 합니다.

## 예상 결과 (검증 포인트)

seed 42, Windows `.venv` 기준입니다.

**15-0 데이터 준비**
- 시장 40개, 인접 시장 쌍 `66`개, 이웃 수 최소 2 / 중앙값 3 / 최대 4
- 군집 `10`개(2×2 블록), 관측 잡음 SD `0.035`
- 성장률의 공간 자기상관(인접 쌍 평균 곱) `+0.779` — 가까운 시장끼리 성장률이 닮습니다

**15-1 지역 실험 설계와 검정력**
- 짝지음 20개 쌍 중 지리적으로 인접한 쌍이 `11`개 — 닮은 시장이 곧 이웃입니다
- 설계 1(사후 비교): 편향 `+0.0167`, 기각률 `0.100`, MDE `0.2518`
- 설계 2(DID): 편향 `+0.0127`, 기각률 `0.358`, MDE `0.1087`
- 설계 3(짝지음+DID): 편향 `+0.0149`, 기각률 `1.000`, MDE `0.0386`
- 설계 4(사후 오염 필터): 분석 단위 `4.6`개, 유효 반복 `180/1000`, **1종 오류율 `0.233`**
- 설계 5(군집 무작위): 노출률 `0.617`, 기각률 `0.080`
- 대조군 B에서 설계 1·2·3·5의 편향이 `±0.003` 안으로 사라집니다 → 파급이 편향의 원인
- MDE 곡선: 시장 10개 `10.22%` → 40개 `3.92%`. 20개에서 30개로 늘리면 오히려 오릅니다

**15-2 시장 단위 합성통제**
- 처치 시장 `35`번(격자 3,5), 인접 시장 `[25, 34, 36]`, 사전 성장률 전체 `8`위
- 추정 계단: ① `+0.0884` → ② `+0.1317` → ③ `+0.1129` → ④ `+0.1092` (참값 `+0.0490`)
- **어느 계단도 참값을 복원하지 않습니다.** 이것이 이 예제의 결론입니다
- 오염량 검산: 인접 가중 합 `0.276` × 파급 `0.0150` = `+0.0041` = 세계 A와 B의 격차
- placebo: 처치 시장 RMSPE 비율 `3.051`, 유사 p값 `0.027` (유의) — 그런데 참값의 2.3배
- 선택 편향 분해: ①은 규모 필터에서(`+0.0013` → `+0.2186`), ②는 성장률 규칙에서(`−0.0925` → `+0.0827`)
- 후보 전수 반복: SCM 평균 편향 `+0.0094`인데 이 시장에서만 `+0.0639`(후보 중 90%가 더 정확)
- 도넛 손익: 전체 풀 평균 절대편향 `0.0250` vs 인접 제외 `0.0389` → **인접 제외가 평균적으로 손해**

**15-3 의사결정 경제학**
- σ = `18.24` (구간 [70,130] 정규 환산)
- 신선식품 임계비 `0.375` → `94`단위 / 내구재 `0.909` → `124`단위, 차이 `30`단위
- 몬테카를로 검산이 두 경우 모두 공식 해와 일치
- 순현재가치: 전이율 0% `+5,515`만원(41개월) / 25% `+386`만원(58개월) / 35% `−1,666`만원(미회수)
- **손익분기 전이율 `26.9%`** — 14장 관행 상한 25%의 근거
- 민감도: 기여이익률 12% → `8.6%`, 임대차 36개월 → `−9.7%`(자기잠식 없어도 기각)
- 두 경로 대조: N=20에서 참값 함의 전이율 `−0.4%` vs 추정 함의 `−130.7%`
- N=10에서 판정이 뒤집힘: 참값 NPV `−4,698`만원(기각) vs 추정 NPV `+5,515`만원(통과)
- 용량 제약: 상방 `+3,419`만원 대 하방 `−4,103`만원 — 비대칭

## 구현에서 결정한 것 (재현 시 참고)

**예측자 선택을 짐작이 아니라 측정으로 정했습니다.** `15-2`의 합성통제 예측자로 처음에는 분기 평균 4개 + 사전 기울기를 썼습니다. 주별 원자료를 쓰면 최적화가 잡음을 쫓아 추세 정합이 밀릴 것이라고 예상했기 때문입니다. 후보 20개 시장으로 네 조합을 비교하니 예상이 뒤집혔습니다.

| 예측자 | 전수 평균 절대편향(전체 풀) | 사전 RMSPE 평균 |
|---|--:|--:|
| 주별 52개 | **0.0250** | 0.0454 |
| 분기 평균 4개 | 0.0322 | 0.0496 |
| 분기 평균 4개 + 기울기 | 0.0293 | 0.0501 |
| 월별 13개 + 기울기 | 0.0250 | 0.0471 |

주별 원자료가 가장 정확했으므로 그것을 씁니다. 판단 근거는 `code/15-2-market-synthetic-control.py`의 `build_predictors` docstring에 남겨 두었습니다.

**처치 시장을 성장률 전체 1위로 고르지 않았습니다.** 전체 1위를 처치로 빼면 볼록조합이 그 궤적을 재현할 수 없어(볼록껍질 밖) 합성통제가 원리적으로 실패합니다. 규모 상위 절반이라는 조건을 두어 최상위 성장 시장 일부가 기증 풀에 남게 했습니다. 현실의 선택 규칙(규모가 받쳐 주고 성장하는 시장)과도 맞습니다.

**설계 4의 실패를 고치지 않고 남겼습니다.** 사후 오염 필터가 1종 오류율을 0.233으로 부풀리는 것은 버그가 아니라 그 설계의 성질입니다. 배정 결과를 보고 표본을 고르면 t분포의 자유도 가정이 깨집니다. 처방(설계 단계 구현 또는 순열 검정)은 본문에 서술로 남겼습니다.
